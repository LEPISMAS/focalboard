\### Reporte de Pruebas Unitarias Redux



\#### Objetivo

Realizar pruebas unitarias sobre el componente store del módulo webapp, ubicado en `src/store`, para validar reducers, acciones, selectores y thunks relacionados con la lógica de estado Redux.



\#### Herramientas utilizadas

\- Jest

\- TypeScript

\- Redux Toolkit

\- npm



\#### Ejecución

Las pruebas se ejecutaron con el siguiente comando:



```bash

npm test -- --coverage
