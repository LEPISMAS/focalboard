\### Explicación de pruebas unitarias del store webapp



Se realizaron pruebas unitarias para el componente store de la aplicación web de Focalboard.



El trabajo se centró en los archivos ubicados en `webapp/src/store`, donde se encuentra la lógica de estado Redux. Las pruebas cubren reducers, acciones, selectores y thunks.



La cobertura obtenida para `src/store` fue:



\- Statements: 90.4%

\- Branches: 73.94%

\- Functions: 92.43%

\- Lines: 90.34%



Con esto se cumplió el objetivo de superar el 90% de cobertura solicitado.
